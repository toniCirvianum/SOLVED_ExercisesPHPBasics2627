Extra password regular expression:

/^(?=.*[a-z])(?=.*[A-Z])(?=.*[0-9])(?=.*[^A-Za-z0-9]).{8,}$/

Requirements:
- At least one lowercase letter
- At least one uppercase letter
- At least one number
- At least one symbol
- At least 8 characters

Explantaion
| Part                 | Meaning                                     |
| -------------------- | ------------------------------------------- |
| `/ ... /`            | Delimiters of the regex in PHP              |
| `^`                  | Start of the string                         |
| `(?=.*[a-z])`        | Must contain at least one lowercase letter  |
| `(?=.*[A-Z])`        | Must contain at least one uppercase letter  |
| `(?=.*[0-9])`        | Must contain at least one number            |
| `(?=.*[^A-Za-z0-9])` | Must contain at least one special character, simbol ^ is negation |
| `.{8,}`              | Must contain at least 8 characters          |
| `$`                  | End of the string                           |
