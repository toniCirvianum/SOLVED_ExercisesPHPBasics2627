# PHP Basics - Solutions

**2026-2027**

This project contains the solutions for the **PHP Basics exercises**.

The main `index.php` file contains a link to every solved exercise.

Some exercises need more than one PHP file because the original activity requires forms, controllers, sessions, reusable templates or external product files.

Exercise 2 also includes a custom `php.ini` example.
